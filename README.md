# Overleaf Nextcloud Integration - v2.1.0

This app can be used to integrate Overleaf V6 into Nextcloud.

**Important**: This will only work with the modified version of Overleaf V6 found [in this repository](https://github.com/Daniel-WWU-IT/overleaf).

## Installation

Before this app can be used, you need to run the following commands within its root directory:

```bash
npm i
npm run build
```
